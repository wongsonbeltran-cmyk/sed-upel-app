Instalar la aplicación

Instala SED UPEL en tu teléfono para acceder desde la pantalla de inicio.

Android: pulsa Instalar aplicación. Si Chrome no muestra el botón, abre el menú ⋮ y busca Instalar aplicación o Añadir a pantalla de inicio.
iPhone/iPad: pulsa Compartir → Añadir a pantalla de inicio → Añadir.
Usa el menú del navegador para añadir SED UPEL a la pantalla de inicio.
Estás usando un computador. La opción Instalar App se reserva para teléfonos. En PC puedes crear un acceso directo desde el menú del navegador.
